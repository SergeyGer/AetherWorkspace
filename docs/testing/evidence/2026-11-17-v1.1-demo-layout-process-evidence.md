## Delivered

- **Compact demo layout (AW-051):** deterministic `demo-grid` broker layout tiles the three real
  top-level windows below a reserved 240 px command strip, clamped to the configured work area with
  minimum usable width/height (unit: `DemoGridReservesTopStripForCommandSurfaceAndStaysWithinWorkArea`).
  WPF Shell gained a **Demo layout** action (`DemoLayoutButton`) that turns itself into a compact top
  command surface and asks the broker to arrange the sample windows below; the full shell remains
  the normal mode.
- **Process/transport evidence (AW-052):** each real WPF sample window shows **PID · app id · actual
  transport** (e.g. `PID 1234 · sample.watchlist · gRPC / Windows Named Pipes`); no hardcoded PIDs.
  The WPF Inspector timeline now renders readable redacted events: Broker IPC, Plan validated, Apps
  registered, Context published, Layout completed, Summary produced, Policy denied. Denial codes
  remain visible in the status/trace surfaces without raw payloads or secrets.
