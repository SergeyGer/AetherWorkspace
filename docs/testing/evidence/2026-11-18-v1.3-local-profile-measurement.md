# v1.3 local model profile + credential lifecycle — evidence (measurement completed)

Evidence for #95 / AW-067. Profile/adapter implementation is merged and CI-tested; a fresh-machine
local measurement was completed on a Linux host (Windows run optional and not performed). #95 is
closed with that explicit host/scope caveat.

## Implemented

- Supported profile **`qwen2.5:7b`** via Ollama, Apache-2.0, pinned model layer
  `sha256:2bada8a7…3730` (4,683,073,952 bytes), license layer `sha256:832dd9e0…e92e`, config digest and
  hardware guidance: [`local-model-profile-qwen2.5-7b.md`](../../evaluation/local-model-profile-qwen2.5-7b.md).
- `LocalModelPlanProvider` (`--planner local`) uses the bounded prompt/strict parser through the local
  egress path; missing model fails typed, never falls back to cloud.
- Optional Windows Credential Manager adapter (`AetherWorkspace/<VAR>`) behind
  `AETHER_CREDENTIAL_STORE`; environment/.env remains the default. Credentials are never logged;
  non-Windows hosts reject the CM source.
- Failure/timeout/malformed-output tests: `LoopbackLocalModelTransportTests`; credential factory
  tests: `SecretProviderFactoryTests`.
- Operator measurement script: `tools/model-eval/Measure-LocalModelProfile.ps1` (real working set and
  evaluation metrics; no fabricated numbers).
