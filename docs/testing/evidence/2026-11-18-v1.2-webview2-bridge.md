## Implementation

- Independent `Aether.SampleApps.WebView2` WPF host, launched by the broker as
  `sample.chart.webview2` (separate PID, real transport badge).
- Local `file`/virtual-host chart page with strict CSP, no remote scripts/CDNs/fetches/host objects;
  local synthetic series only.
- Strict bounded bridge: host projects approved `fdc3.instrument` contexts (`NRST`, `VEGA`, `ORIN`)
  with classification + broker trace + synthetic series; JS validates the same allowlist, rejects
  unknown payloads and posts a render acknowledgement to the WPF automation surface.
- WebView2 Evergreen Runtime documented as prerequisite; forced fallback keeps the host alive and
  shows guidance. `AETHER_WEBVIEW2_FORCE_FALLBACK=1` E2E exercises that path.
- Windows registry, launch token `WEBVIEW2_CHART_EXE`, packaged bundle, release workflow and CI
  runtime setup are wired; the default six-action reference workflow is unchanged.
