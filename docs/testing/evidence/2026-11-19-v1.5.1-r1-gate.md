## Video review — REJECTED, superseded

The first V151 video build passed technical validation but failed human review:

1. burned-in text subtitles were present (reviewer wants voiceover only, no on-screen text);
2. after the context change around 45 s the three subordinate windows were partly covered by the
   large Shell window at the top;
3. the Instruction field was populated instantly instead of appearing as user typing.

Fixes prepared after review: V151 is caption-free and mixes a reviewed synthetic voiceover
(`docs/demo/media/narration-v151.mp3`); the capture now types progressively, minimizes the command
surface and applies a full-work-area side-by-side layout so all three windows are visible. A new
capture is required because windows hidden behind the Shell cannot be recovered from the old raw
recording. The initial capture/video manifests are kept here as an archived rejected revision, not as
approved media.
