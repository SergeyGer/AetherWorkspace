# v0.3.1 — AW-024 external FDC3 interoperability increment

Patch release completing the first external-interoperability increment for AW-024, plus
cost-optimized model defaults for the upcoming v0.4 work.

## Highlights

- **Official FDC3 3.0 standards artifacts:** vendored `context`, `instrument` and
  `organization` JSON Schemas from `finos/FDC3` at pinned commit
  `c6adda7a1f66d97d03809343852a4bfc0806f859` (Apache-2.0, provenance and licence included).
- **Independent external validation:** Python `jsonschema` validator (different
  language/runtime from the .NET product code) validates all supported fixtures and
  trusted-catalog payloads against the official schemas — 7/7 payloads valid — and emits a
  machine-readable report in CI. `.NET` contract tests validate the same payloads and assert
  schema provenance pinning.
- **FDC3 3.0 metadata projection:** broker-authenticated provenance (`source.appId`,
  `source.instanceId`, ISO-8601 timestamp, `traceId`) is mapped to the FDC3 3.0
  `ContextMetadata` shape.
- **Deviation register + research:** `docs/fdc3/interop-report.md` covers the FDC3 3.0
  conformance landscape (three conforming agents: FDC3 Sail, interop.io io.connect Browser
  5.0, Morgan Stanley fdc3-web; JS Desktop Agent API conformance framework; experimental
  DACP) and the plan for the DACP/Sail runtime-interop increment.
- **Model defaults (v0.4 prep):** `.env.example` now defaults to cost-optimized models —
  OpenAI `gpt-4o-mini`, Gemini `gemini-2.5-flash-lite` ($0.10/$0.40 per 1M tokens), local
  `qwen2.5:3b` — with rationale and pricing sources in `docs/evaluation/model-selection.md`.
- CI: Linux job runs the independent FDC3 schema validator on every build.

## Evidence

- `tests/Aether.Fdc3.Tests`: 20/20 tests (including 5 official-schema interop tests).
- Independent validator: 7/7 payloads, 0 failures; report in the CI artifact.
- All CI jobs green (Linux, Windows, WPF UI automation) are required by the `main` branch
  protection rule.

## Explicit non-claims

No FDC3 conformance, certification or third-party Desktop-Agent runtime interop is claimed.
The supported surface remains a declared bounded subset; the conformance framework targets
the JS Desktop Agent API and a DACP/WCP adapter is future work.
