# v0.4.4 — restore TRX aggregation helper

Patch release fixing a harness regression introduced in v0.4.3.

## Fixed

- `tools/windows-test/Run-AetherTests.ps1`: the `Read-TrxCountersAggregate` helper was dropped
  during the deterministic per-project rewrite. The first v0.4.3 reference run executed **all
  eight test projects successfully** (exit 0 each, including the E2E suite) but then failed at
  aggregation with "Read-TrxCountersAggregate is not recognized" → `FAIL_HARNESS` (exit 2).
- v0.4.4 restores the helper and adds a static validation step used during development: every
  custom helper command invoked by the script must have a definition (only PowerShell built-in
  cmdlets and `git` remain external).
- R1 evidence/run tables record the v0.4.3 harness-only failure and the fix.

## Evidence status

- Physical Windows 11 reference runs on approved SHAs: v0.4.0 (`e7007af`) — developer-smoke,
  daily-smoke, release-full PASS; v0.4.1 (`4a2796e`) release-full PASS; v0.4.2 (`d44e6ba`)
  release-full PASS; v0.4.3 (`303f4d7`) — all 8 projects PASS, harness aggregation failure
  fixed here.
- Authoritative suite composition: 445 portable + 2 windows-ui + 2 desktop-e2e = 449 passed.
