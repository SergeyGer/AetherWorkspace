# v1.5.1 — Workspace UX & AI Command Center

**Status: release candidate — not yet tagged. Physical R1 gate PASS; revised V151 video review and
publication approval pending.**

This file is the release-notes source. It must not be treated as a published release until the
physical Windows 11 evidence and video review are recorded below and the tag is created through the
normal release process.

## Highlights

- **AI Command Center** — prominent instruction editor with New / Save / Duplicate / Delete / saved
  instruction picker, truthful `CLASSIFYING → PLANNING → VALIDATING → AUTHORIZING → EXECUTING`
  progress, submission run context and a read-only validated plan preview.
- **Trusted application selection** — Select Apps panel backed by the live broker catalog/health;
  Launch Selected and per-app Launch / Focus / Stop / Restart use the existing allowlisted broker,
  never a parallel launcher.
- **Preferred / Strict launch scope** — a trusted `LaunchSelectionContext` is passed adjacent to the
  untrusted plan. Strict mode pre-authorizes the entire plan before step 1; an unselected
  `LaunchApp` is denied as `plan.selection.app_not_selected` with no side effects (ADR-014).
- **Local instruction templates** — strict JSON, atomic writes, defensive load/quarantine, three
  synthetic starters, user-scoped under `%LOCALAPPDATA%\AetherWorkspace\instructions`; never
  Git-tracked and never trusted without full revalidation.
- **WPF + WebView2 demo preset** — selects Watchlist + Risk + the independent WebView2 chart in
  Strict mode; deterministic planner supports the trusted chart variant.
- **Execution details** — Summary / Plan preview / Trace / Processes / Inspector expose validation,
  transport, broker endpoint, PIDs, redacted event trace and audit status without raw payloads.

## Security and privacy

- No new executable/URL/shell surface: the pure ActionPlan language is unchanged.
- The model cannot forge the operator selection; selection context is out-of-band trusted state.
- PUBLIC-only cloud with explicit consent is unchanged; INTERNAL/RESTRICTED/UNKNOWN cloud routing
  remains rejected (ADR-011).
- Raw instruction text and payloads are not written to metadata audit; the Processes tab shows
  transport, endpoint/identity and PIDs, not prompts.
- Saved templates store only text/title/timestamps/schema; no credentials or raw PII.
