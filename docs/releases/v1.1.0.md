# AetherWorkspace v1.1.0 — Demo-ready

The v1.1 milestone makes the policy-governed desktop workspace **demonstrable end to end on a
physical Windows 11 laptop** and completes the v1.0 measurement gaps with honest, per-ID evidence.
This remains an independent reference implementation of synthetic demo data — not production
software, not a compliance certification, and not a third-party compatibility claim.

## Highlights

- **Track B hero demo (primary):** a real LLM-assisted plan under explicit PUBLIC consent
  (`planner=cloud-plan`, `usedModel=true`) is validated and executed by the deterministic policy
  engine; three real WPF sample processes synchronize typed context over authenticated Windows named
  pipes, with real PIDs and trace provenance. Clean physical capture:
  [evidence](https://github.com/SergeyGer/AetherWorkspace/blob/main/docs/testing/evidence/2026-11-18-v1.1-track-b-demo-gate.md),
  [MP4](https://github.com/SergeyGer/AetherWorkspace/blob/main/docs/assets/demo-hero.mp4),
  [GIF](https://github.com/SergeyGer/AetherWorkspace/blob/main/docs/assets/demo-preview.gif).
- **Track A deterministic demo (secondary):** the same workflow with `deterministic-grammar` /
  `usedModel=false`; never captioned as AI-generated.
- **Local recording pipeline:** approved-SHA trust/preflight, detached worktree, localhost OBS
  WebSocket control, temporary taskbar auto-hide with exact restore, WPF `Category=DemoCapture`
  scenario, measured-event captions, FFmpeg MP4/GIF build, codec/black-frame validation and
  operator human review (`tools/demo/`).
- **Demo layout and process evidence:** compact `demo-grid`, real PID/app-id/transport badges and a
  readable Inspector event view.
- **UI responsiveness baseline (AW-066):** 100-cycle physical report with pinned hardware/display/power
  profile — command p50/p95/p99 = **3/8/10 ms**, frame-probe p95 0.48/0.94/1.78 ms, working set
  219.9→319.3 MB, managed memory 12.0→22.5 MB, zero threshold violations. Evidence:
  [2026-11-18 UI report](https://github.com/SergeyGer/AetherWorkspace/blob/main/docs/testing/evidence/2026-11-18-v1.1-ui-responsiveness.md).
- **Per-WT matrix (AW-065):** automated WT rows PASS from the reference-full ledger; manual rows are
  recorded as **formal exceptions, not PASS** (see below).

## Formal exceptions (not PASS)

The v1.1 reference-desktop matrix records these manual rows as **FORMAL_EXCEPTION** per operator
decision; they are **not** claimed as verified and are tracked by
[#120](https://github.com/SergeyGer/AetherWorkspace/issues/120):

- WT-05-05 — DPI 125%/150% with rollback (only the 100% baseline was used);
- WT-05-06 — focus/keyboard/modal walkthrough;
- WT-05-03 — controlled display-topology change and recovery;
- WT-05-09 — physical child crash/hang recovery (Linux fault injection covers protocol logic only);
- WT-05-08 — manual Inspector/export privacy confirmation (automated audit/redaction tests pass).

Evidence register:
[2026-11-18 WT formal exceptions](https://github.com/SergeyGer/AetherWorkspace/blob/main/docs/testing/evidence/2026-11-18-v1.1-wt-formal-exceptions.md).

## Other boundaries

- Track B requires a locally configured provider credential and PUBLIC consent; no key or raw capture
  is committed. The demo is silent-first and synthetic-data-only.
- The portable Windows bundle is unsigned; there is no signed installer, reproducible-build guarantee
  or production support claim.
- The UI responsiveness figures are local UI-thread measurements, not IPC throughput and not a
  hardware-independent SLA.

## Verification

- Required CI lanes: Linux build/tests/headless demo; Windows build/tests/named-pipe demo; Windows
  real-WPF UI automation (FlaUI), plus the reference-desktop physical suites.
- Release assets: Windows x64 desktop bundle, headless binaries, source snapshot, SPDX SBOM and
  SHA-256 checksums; verify with `tools/release/Verify-Release.ps1` (expect `VERIFY PASS`).
- A fresh packaged-bundle smoke runs inside the release workflow and #82 closes on the v1.1.0 run.
- Physical release-full gate on the release commit is recorded in the release evidence/gate summary
  supplied with this release.
