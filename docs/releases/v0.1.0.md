# v0.1.0 — M0 foundation + MVP vertical slice

First public implementation baseline of AetherWorkspace (synthetic data only).

## Highlights

- .NET 10 solution with warnings-as-errors, pinned SDK/packages, Linux + Windows CI.
- Versioned Protobuf broker contracts, strict JSON `ActionPlan`/app-manifest/context-catalog models and published JSON schemas.
- Local gRPC broker over Windows named pipes / Unix domain sockets: allowlisted registry and launcher, process-bound sessions with single-use tokens, capability checks, bounded typed channels, deterministic window layout, health state and metadata-only hash-chained audit.
- Source-first classification, deny-by-default classification policy with explicit cloud consent, single egress gateway.
- Deterministic plan validator + bounded executor with explicit states, deadlines, cancellation and compensation.
- Deterministic reference planner, optional policy-gated adapters and a private local deterministic summary.
- Three independent synthetic sample apps (headless executed on CI, WPF build-verified), WPF shell and headless E2E host.
- Reference workflow demo, 100-entry unsafe-plan corpus, multi-process E2E tests, audit-tamper tests, benchmark harness with measured IPC baseline.
- Documentation: README, quickstart, architecture, ADRs, threat model, contracts, benchmarks, limitations, implementation status.

## Evidence

- Build: Release, 0 warnings / 0 errors (Linux cross-build incl. WPF).
- Tests: 316 automated tests at this milestone (contract, security, execution, AI, broker, workflow, E2E).
- Reference workflow demo succeeds; RESTRICTED data produces zero external AI calls and a verified audit chain.

## Known limitations

Synthetic data only; no production or compliance claims. Windows runtime evidence is produced by the Windows CI job. X (docking) is excluded from the MVP. No release binaries or SBOM are attached to this milestone release; source archives are provided by GitHub.
