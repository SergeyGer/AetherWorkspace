# AetherWorkspace v1.0.1 — corrective release (packaging, evidence governance, docs)

Corrective release responding to the independent v1.0.0 specification-conformance gap assessment.
Full finding-by-finding disposition:
[`docs/audit/2026-11-16-gap-assessment-response.md`](../../docs/audit/2026-11-16-gap-assessment-response.md).

## Fixed

- **G-01 — real Windows desktop distribution.** The release workflow now has a Windows x64
  packaging job that publishes the WPF Shell, the three WPF sample applications, the broker and
  the trusted registry/contexts/fixtures into
  `AetherWorkspace-<tag>-windows-x64-desktop.zip`, with a one-command launcher
  (`Start-AetherWorkspace.ps1`) and a README. The headless runtime archive is renamed
  `AetherWorkspace-<tag>-headless-binaries.zip` so it is no longer mistaken for the desktop product.
  A Windows job builds and runs desktop/UI smoke tests before assets are published.
- **G-08 — stale status/limitations documents.** `docs/IMPLEMENTATION_STATUS.md` and
  `docs/limitations.md` are reconciled to released tags and current evidence; CI doc-consistency
  tests guard the known stale assertions and the README/Wiki split.
- **G-09 — release provenance.** Acceptance evidence now records R1 approved SHA `6ec0b9e`, tag
  target `c67c3eb`, the documentation-only diff between them, and why no full R1 rerun was needed.
- **G-12 — machine-readable evidence.** Added a curated, privacy-safe
  `*.acceptance.manifest.json` with run/suite/counter/environment data, evidence-file hashes and
  explicit raw-artifact retention policy.
- **G-11 (partial) — release gate.** Publication now requires the Windows desktop build/smoke job,
  not only the Ubuntu build.

## Formally narrowed scope (explicit deviations)

- **G-03 cloud policy:** v1.x is **PUBLIC-only cloud** (ADR-009). Conditional INTERNAL-cloud
  token-vault routing is excluded, not implemented; the vault remains a tested local primitive.
- **G-05 contract studio:** the v1.x studio is **template-based and review-only** (ADR-010); no
  LLM generation or proto compilation is claimed.

## Remaining accepted gaps (planned beyond v1.0.x)

Model-accuracy/latency corpus (G-02), full WT-04/WT-05 matrix incl. DPI/focus/responsiveness
(G-04/G-06), local-model/credential-manager lifecycle (G-10), and full FDC3/docking scope
(G-07 accepted; docking not planned) are documented in the response page. They are not relabeled
as PASS.

## Verification

- Required CI lanes (Linux, Windows, WPF UI) plus the new Windows desktop release job.
- `tools/release/Verify-Release.ps1` on the published assets (desktop ZIP, headless ZIP, source,
  SBOM): expected **VERIFY PASS**.
- Operator clean-machine check of the Windows desktop bundle is the remaining G-01 closure step:
  extract, run `Start-AetherWorkspace.ps1`, execute the reference workflow, close cleanly.
