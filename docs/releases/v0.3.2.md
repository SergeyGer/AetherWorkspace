# v0.3.2 — AW-024 DACP runtime interoperability with FINOS Sail

Patch release closing the practicable scope of AW-024: in addition to the official-schema
validation shipped in v0.3.1, the declared FDC3 subset is now exercised at runtime through
an **independent FDC3 implementation**.

## Highlights

- **Test-only DACP interoperability harness** (`tools/fdc3-interop/`): the bounded
  AetherWorkspace FDC3 surface is driven through the FINOS
  [`@finos/sail-headless-agent`](https://www.npmjs.com/package/@finos/sail-headless-agent)
  `3.0.0-beta.1` headless Desktop Agent — an independent DACP implementation
  (Apache-2.0) — using official FDC3 3.0 DACP wire messages.
- **5/5 runtime interop checks passed:** `fdc3.instrument` broadcast on the `default` app
  channel with Sail-enriched metadata (`source.appId`, authoritative timestamp, our
  `traceId` preserved); `fdc3.organization` broadcast; `ViewInstrument` intent resolved to
  `sample.watchlist` (the app declaring the intent); intent result routed back to the
  raiser. Machine-readable report is produced in CI (`.aether/dacp-interop-report.json`).
- CI Linux job installs the pinned Node dependencies and runs the DACP interop harness on
  every build, next to the independent Python JSON-Schema validator.
- Docs: `docs/fdc3/interop-report.md` records the interop evidence and the remaining
  non-goals; `docs/IMPLEMENTATION_STATUS.md` marks AW-024 **done for the practicable
  scope**; issue #24 is closed with evidence.
- v1.0 distribution policy confirmed: public MIT sources, unsigned portable framework-dependent
  archives + SPDX SBOM + SHA-256 checksums; no installer/code signing planned for v1.0 scope.

## Explicit non-claims

No FDC3 conformance or certification is claimed. The official conformance suite targets the
JavaScript Desktop Agent API, which this policy-aware .NET broker does not implement. A
production DACP server wrapper around the broker remains optional future work.

## Evidence

- Local: DACP harness 5/5 checks, 6 exchanges; FDC3 tests 20/20; full test suite green.
- CI: Linux (schema validator + DACP interop + egress + SBOM), Windows (build/tests/named-pipe
  demo/benchmark/egress), WPF UI automation — all required checks green.
