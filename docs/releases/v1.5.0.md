# AetherWorkspace v1.5.0 — heterogeneous UI, hybrid AI, privacy gate and extension decisions

Cumulative milestone release covering v1.2–v1.5. The deterministic runtime and evidence boundaries
are unchanged: synthetic data, local-first by default, no FDC3 conformance claim, unsigned portable
distribution. Detailed evidence is linked below; physical v1.2 gate PASS (2026-11-19) and the
local-profile measurement are recorded in this release.

## v1.2 — heterogeneous UI (WebView2)

- Independently launched **WebView2 chart host** (`sample.chart.webview2`) with a local-only JS
  renderer (no CDN/network/host objects), strict CSP via a local virtual host.
- Bounded **.NET host→JavaScript bridge** for broker-approved `fdc3.instrument` contexts
  (NRST/VEGA/ORIN), JS render acknowledgement back to the WPF automation surface, rejection of
  unknown/unapproved payloads.
- Evergreen WebView2 Runtime prerequisite documented; forced-fallback path and Windows E2E coverage.
- CI: Linux/Windows build, Windows WPF UI E2E with real WebView2 (`WebView2ChartBridgeTests`,
  `WebView2FallbackTests`).
- **Physical Windows 11 gate PASS** (2026-11-19, approved SHA `85e5466`): trust/reference-full/WT
  ledger/UI responsiveness all PASS; desktop E2E 8/8, portable 590/590, shell UI 3/3, layout05 4/4;
  100-cycle UI measurement had 0 threshold violations. Evidence:
  [`v1.2 physical gate`](../testing/evidence/2026-11-18-v1.2-webview2-bridge.md).

## v1.3 — hybrid AI and evaluation

- **Per-capability provider configuration:** `AETHER_PLANNER_PROVIDER` / `AETHER_SUMMARY_PROVIDER`
  with `AETHER_MODEL_PROVIDER` fallback; OpenAI-compatible, Gemini, local/Ollama and deterministic.
  Fail-closed validation (`provider.config_invalid`), truthful planner provenance, no silent brand
  replacement.
- **Supported local profile:** `qwen2.5:7b` via Ollama, Apache-2.0, pinned model/license layer
  digests and hardware guidance; optional Windows Credential Manager source; environment/.env default.
- **Gold-corpus evaluation:** 120 labelled synthetic command items (80 canonical plan, 40
  adversarial negatives), repeated trials, semantic plan/denial accuracy, p50/p95/p99 latency and
  TTFT (streaming OpenAI transport), labelled token/cost estimates and hardware fingerprint.
  Live `gpt-4o-mini` run (2 trials/240 requests): **98.75% plan accuracy / 100% denial accuracy**,
  TTFT **531.5 / 822.1 / 1213.4 ms**, latency **1633.0 / 2172.1 / 2723.8 ms**, estimated cost
  **$0.026556**. The one plan miss and the actual-vs-estimated cost limitation are explicit.
- Evidence: [`provider config/eval harness`](../testing/evidence/2026-11-18-v1.3-provider-config-and-eval-harness.md),
  [`live OpenAI report`](../evaluation/results-2026-11-18-openai-gold-corpus.md),
  [`local profile measurement`](../evaluation/results-2026-11-18-local-qwen2.5-7b.md) (fresh Linux
  host: 4.9 GB local-inference RSS, latency ~23.5 s, limited 4-item scope; no Windows run claimed).

## v1.4 — privacy gateway decision

- **ADR-011: sanitized INTERNAL cloud routing is rejected** for v1.x; cloud remains PUBLIC-only.
  `PolicyEngine` hard-disables the latent `AllowSanitizedInternal` branch even with a custom policy
  flag; the token vault remains a local primitive and is architecturally guarded out of
  `src/Aether.AI`. Tests prove default denial and zero transport calls for RESTRICTED/UNKNOWN.
- No zero-leak, anonymization or PII-guarantee claim is made.

## v1.5 — extension decisions

- **ADR-012: Electron adapter NO-GO** for v1.x. Measured upstream Electron Windows ZIP ~151 MiB vs
  WPF sample ~1.9 MiB, WebView2 host ~4.0 MiB and complete desktop bundle ~3.6 MiB; the existing
  WebView2 E2E already proves independent-process typed-context sync. No dependency/prototype added.
- **ADR-013: keep the bounded FDC3 subset.** Explicit rejected-surface matrix: user/global channels,
  broader contexts/intents/listeners, directory federation, Desktop Agent Bridge and conformance
  claims. Rejection tests added; no conformance wording.

## Boundaries / known limitations

- Synthetic demo data only; no production, compliance, conformance or SLA claim.
- Cloud is PUBLIC-only with consent; INTERNAL/RESTRICTED/UNKNOWN stay local. The loopback local model
  is not automatically air-gapped; provider-side logging remains outside our control.
- UI responsiveness figures are local UI-thread measurements, not IPC throughput. TTFT is available
  only for the streaming OpenAI-compatible transport; Gemini/local report it as unavailable.
- Electron/FDC3 surface decisions are ADR-recorded no-go/no-expansion, not implementation claims.
