# v0.4.0 — privacy controls, model routing and Windows 11 test infrastructure

Fourth milestone release: v0.4 feature stream (privacy, model routing/evaluation, adversarial
egress evidence) plus the Windows 11 reference-desktop testing infrastructure needed for
physical desktop validation.

## Highlights

### Models and evaluation (AW-026 / AW-028)

- Real provider adapters: OpenAI-compatible chat completions and a new native **Google
  Gemini** `generateContent` transport, both behind the single egress gateway and credential
  provider; `AETHER_MODEL_PROVIDER` selects the adapter, keys load only from git-ignored `.env`.
- **Explicit model router:** cloud attempts only for `PUBLIC` + cloud enabled + recorded
  consent + configured provider; `INTERNAL`, `RESTRICTED` and `UNKNOWN` never attempt cloud and
  use local model/deterministic fallbacks. Decision + reason exposed in shell JSON output.
- **Evaluation harness** (`tools/Aether.ModelEval`) + synthetic command corpus; first real
  smoke run with cost-optimized models (`gpt-4o-mini`, `gemini-3.1-flash-lite`): 6/6 provider
  responses and 6/6 syntactically valid bounded plan shapes each, avg latency ~1.3–1.4 s,
  estimated total cost < $0.01. Sanitized evidence in `docs/evaluation/results-2026-11-15.md`.

### Privacy (AW-025 / AW-027)

- Detector escalation: extended deterministic sensitive-entity detection (account/IBAN-like,
  email, phone, LEI, ISIN) with an explicit never-downgrade classification escalator and
  fail-closed UNKNOWN on detector failure.
- Session token vault: session-scoped masking/de-masking with capacity/expiry/cancel semantics,
  thread safety and audit snapshots that never contain raw tokens.

### Adversarial egress (AW-029)

- Router + egress regression tests prove `INTERNAL`/`RESTRICTED`/`UNKNOWN` never reach a cloud
  transport; CI still runs the OS-level blocked-egress workflow (L1) and Windows Firewall
  blocked-egress demo (W1).

### Windows 11 reference-desktop test infrastructure (AW-039–AW-042)

- Published reference-desktop run diagram (`docs/testing/reference-desktop-automated-test-run.png`),
  `docs/testing/windows11-reference.md` test strategy and `docs/testing/reference-desktop.md`
  lifecycle documentation.
- Local PowerShell orchestrator (`tools/windows-test/`): reviewed full-SHA approval, unlocked
  interactive-session preflight, single-instance mutex, detached worktree, environment
  manifest, machine-readable run result, owned-PID cleanup and explicit SKIPPED_* taxonomy.
  The laptop is never a GitHub runner.
- Windows Named Pipes GUI E2E project (`tests/Aether.Desktop.E2E.Tests`): real broker over
  named pipes + WPF shell + three sample processes, FlaUI semantic locators, WT-04
  privacy/UI-status assertions and failure evidence capture; CI `windows-ui` lane extended.
- New testing backlog issues AW-039–AW-046 (planning artifacts; see GitHub).

### Fixes

- `.env` parser now strips trailing `# comment` from unquoted values (and preserves URL
  fragments), so `OPENAI_MODEL=gpt-4o-mini  # comment` resolves correctly.
- Gemini model default updated to an available cost-optimized tier after a live availability
  check (`gemini-2.5-flash-lite` is closed to new users).

## Explicit non-claims

No FDC3 conformance, compliance certification, fixed-latency claim or Windows 11 hardware
performance claim. The reference-desktop suite runs on the operator's laptop only under
explicit trust/preflight rules; GitHub-hosted Windows CI remains the mandatory gate. Raw
screenshots/logs are never auto-uploaded to public artifacts.

## Evidence

- Full test suite green (portable), Windows CI (build, tests, named-pipe demo/benchmark,
  blocked egress), WPF UI automation, and the first real provider smoke run.
- Raw evaluation reports are local/git-ignored; curated sanitized results are committed.
