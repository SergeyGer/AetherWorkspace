# Planning baseline

This directory preserves the design and delivery baseline that the implementation
follows; it is **not** a statement of completion.

| File | Purpose |
|---|---|
| `technical-specification-v3.0.md` | Product/architecture requirements (converted from the supplied v3.0 docx, read-only source). |
| `implementation-release-plan-v3.0.md` | Ordered milestones, issues AW-001…AW-038, gates (converted from the supplied v3.0 docx). |
| `github-planning-kit/` | Offline GitHub Planning Kit v3.0: 38 issue Markdown files, issue manifest, Wiki pages, optional importer script and templates. |
| `v1.1-v1.5-execution-plan.md` | Active execution plan for the demo/development brief `AW-DP-001`: milestones v1.1–v1.5, GitHub issues AW-047…AW-067, v1.0 gap plan and acceptance/CI approach. |

Stable ids (AW-…) are planning identifiers, not GitHub issue numbers. After importing
issues, replace prerequisite ids with GitHub dependency links. Milestone names denote
capability gates, not calendar deadlines. Current implementation status against this
plan is tracked in [`../IMPLEMENTATION_STATUS.md`](../IMPLEMENTATION_STATUS.md).
