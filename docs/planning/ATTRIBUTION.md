# Source attribution and handling

The files in this directory were converted from the attachments supplied for this
project (AetherWorkspace Technical Specification v3.0, Implementation & Release Plan
v3.0, and the GitHub Planning Kit v3.0 zip). Conversion into Markdown preserved the text
content; formatting artefacts from the docx conversion may remain.

Rules for this directory:

- Treat the v3.0 documents as the design baseline, not as measured results or a plan
  that has been completed.
- Security, privacy and performance statements in the baseline are engineering
  objectives; only evidence committed in this repository counts as verification.
- Do not add claims, affiliations or customer names to the planning baseline.
- Examples are synthetic; never add real financial or personal data to planning files.
