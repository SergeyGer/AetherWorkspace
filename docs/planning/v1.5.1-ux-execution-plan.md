# v1.5.1 — Workspace UX & AI Command Center execution plan

Status: **implementing**. Baseline: v1.5.0. This plan turns the v1.5.1 technical specification into
reviewable phases. Each phase has a GitHub Issue with acceptance criteria and evidence; no phase is
PASS until its evidence is committed.

## Delivery model

Feature branch → PR + required CI → physical Windows 11 verification (where applicable) → tagged
release. Linux/Hetzner authors code, tests and scripts; the Windows 11 laptop remains the interactive
R1 reference and must not be remotely controlled. The operator approves a full 40-hex SHA before a
physical run or capture. Failed preflight is SKIPPED/INCONCLUSIVE, never PASS.

## Security invariants

- The pure plan language still has no executable paths, shell commands or arbitrary URLs.
- Selection context is trusted Shell state, adjacent to the plan; the model cannot forge it.
- Strict selection is checked for the whole plan before step 1; no partial side effects.
- Automatic cloud transfer of INTERNAL/RESTRICTED/UNKNOWN remains forbidden. PUBLIC-only + explicit
  consent is unchanged.
- Selection mode, allowed-app count, denied app ID and reason code may be audited; raw instruction
  text and payloads are not.
- Saved templates are local user-scoped data, never credentials or model-approval objects, and are
  fully revalidated on every run.
- No remote unattended desktop access, arbitrary model code or Electron runtime.
