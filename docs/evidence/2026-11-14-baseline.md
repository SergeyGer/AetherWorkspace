Key acceptance evidence contained in the suites:

- Every one of the 100 documented unsafe plans is denied before any handler invocation.
- `RESTRICTED`/`UNKNOWN` cloud paths observe **zero** external transport calls.
- Audit chains verify; a modified historical entry and a deleted entry are both detected.
- Session handshake negatives: unknown/replayed/expired token, identity mismatch,
  unsupported protocol, session expiry.
- Registry/launcher negatives: unknown app, unallowlisted executable, path traversal.
- Channel behaviour: FIFO ordering, bounded overflow accounting, deduplication, clearance
  filtering, subscriber isolation.
- E2E: reference workflow across independent processes, repeatability, denial paths,
  offline/missing-model path, crash + bounded restart.

  tested with doubles.

- Any PII detection precision/recall, performance guarantee for reference Windows
  hardware, or FDC3 conformance claim.
