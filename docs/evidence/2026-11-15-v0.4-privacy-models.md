## Test/quality totals

Full portable suite after v0.4: **445 tests** — contract 41, security 126
(50 previous + 47 escalation + 29 vault), execution 140, AI 37 (27 + 10), broker 56,
workflow 9, FDC3 20, E2E 16. Plus Windows-only suites: WPF UI automation (2) and
reference-desktop Named-Pipes GUI E2E. Release build 0 warnings / 0 errors.

## Real-provider smoke (synthetic PUBLIC corpus)

- OpenAI `gpt-4o-mini`: 6/6 provider responses, 6/6 syntactically valid bounded plan shapes,
  avg latency ~1.4 s, estimated cost < $0.01.
- Gemini `gemini-3.1-flash-lite`: 6/6 responses, 6/6 valid plan shapes, avg ~1.2 s.
  `gemini-2.5-flash-lite` was unavailable to new users (live 404), so the next cheapest
  available tier was selected after a live check.
- Model output remains untrusted; only the deterministic validator/authorizer can lead to
  execution. Raw reports stay in git-ignored `.aether/evaluation/`.

## Not evidenced here / remaining

  the laptop execution + curated evidence is the next step under AW-039–AW-042).

  (adapter integration remains).
- No local-model (Ollama) inference executed; a missing model is reported unavailable, not pass.
- No formal precision/recall for detectors (needs a labelled corpus); no model quality ranking
  from the 6-command smoke.
- No Windows 11 hardware performance/DPI/multi-monitor validation (v0.5 scope).
- Memory-only token vault (no OS-backed encryption), local model trust boundary and policy
  approval for private deployments remain future work.
