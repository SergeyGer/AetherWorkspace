# Model evaluation smoke — 2026-11-15 (v0.4, synthetic PUBLIC data)

Real-provider smoke run of the v0.4 evaluation harness (`tools/Aether.ModelEval`) against the
synthetic bounded command corpus (`docs/evaluation/command-corpus.json`). **No personal, live
financial or restricted data was sent.** API keys were loaded only from the local git-ignored
`.env` file and are not printed, logged or stored in this report. Cost/token figures are
character-based estimates, not provider billing.

## Environment

- Harness: `tools/Aether.ModelEval` (Release), provider adapters from `src/Aether.AI`.
- Corpus: 6 synthetic commands (5 normal + 1 adversarial plan-injection sample).
- Date: 2026-11-15, in-repo sandbox host, outbound HTTPS enabled.
- Product security: model output is untrusted; the product validator/authorizer remains the
  enforcement point (the adversarial command producing syntactically valid JSON is **not**
  executed by this harness).

## OpenAI

- Provider adapter: `openai` via `HttpCloudModelTransport` (OpenAI-compatible chat completions)
- Model: `gpt-4o-mini`
- Result: **6/6 provider responses**, **6/6 syntactically valid bounded plans**, avg latency **1381 ms**, estimated total cost **$0.000228**

## Interpretation

- Both provider adapters work end-to-end with the cost-optimized models and emit JSON plan
  shapes that the deterministic validator can inspect; plan **semantic** validity and
  authorization are still enforced by the product (the evaluation only checks the bounded
  JSON shape).
- These are 6-command smoke numbers, not a statistically meaningful quality benchmark.
- Next evaluation step: expand the corpus, add TTFT/first-token timing, real token usage from
  provider responses, repeated trials, and quality scoring against deterministic plans.
