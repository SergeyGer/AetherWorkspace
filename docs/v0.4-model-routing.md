# Provider configuration, model routing and evaluation

Status: v0.4 baseline extended by **v1.3** (2026-11-18): per-capability provider selection, local ~/.env and optional Windows Credential Manager sources, local-model planning route and a fail-closed configuration validator. Synthetic data only; no production,
compliance or fixed-performance claims.

## Provider configuration

Configuration is resolved from environment variables or an explicitly loaded, git-ignored
`.env` file (`--env-file`, in-memory secret provider; the process environment is not
mutated; values are never logged). Defaults target the cheapest capable models; see
[`docs/evaluation/model-selection.md`](evaluation/model-selection.md).

| Variable | Purpose |
|---|---|
| `AETHER_MODEL_PROVIDER` | Fallback provider for both capabilities: `openai` (default), `gemini`, `local`, `deterministic` |
| `AETHER_PLANNER_PROVIDER` | Planning capability provider (overrides the fallback) |
| `AETHER_SUMMARY_PROVIDER` | Summarization capability provider (overrides the fallback) |
| `AETHER_CREDENTIAL_STORE` | `environment` (default) or `windows-credential-manager` (optional; see credential lifecycle below) |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` | OpenAI-compatible chat-completions adapter |
| `GEMINI_API_KEY`, `GEMINI_BASE_URL`, `GEMINI_MODEL` | Native Gemini `generateContent` adapter (`x-goog-api-key`; default `gemini-3.1-flash-lite`) |
| `AETHER_LOCAL_MODEL_ENDPOINT`, `AETHER_LOCAL_MODEL` | Optional loopback local model (Ollama-compatible) |
| `AETHER_CLOUD_ENDPOINT`, `AETHER_CLOUD_API_KEY`, `AETHER_CLOUD_MODEL` | Generic OpenAI-compatible fallback adapter |

Per-capability resolution is implemented by `ModelProviderCatalog`. Unknown provider names, malformed
endpoints, non-HTTPS cloud endpoints, non-loopback local endpoints and empty model ids are
**configuration errors**; the router then takes the deterministic/local private fallback and marks
`provider.config_invalid`. A merely missing key/endpoint is *unconfigured* and reports
`provider.cloud_not_configured` — it is never silently replaced with a different brand. The headless
`providers` block exposes `plannerProvider`, `summaryProvider`, `providerConfigurationError` without
any network I/O. API keys are referenced by variable name only and never printed.

## Model routing policy

`ModelRouter` makes the route explicit and testable per AI task:

| Data classification | Cloud attempt | Route |
|---|---|---|
| `PUBLIC` | Only when cloud is enabled **and** consent is recorded **and** provider is configured | cloud adapter (selected provider/model) |
| `INTERNAL` | Never by default | local model if configured, else deterministic local |
| `RESTRICTED` | Never | local model if configured, else deterministic local |
| `UNKNOWN` | Never (fail closed) | local model if configured, else deterministic local |

Cloud gating is additionally enforced by the single `EgressGateway` (policy + audit), so a
routing bug cannot bypass classification/consent enforcement. The headless shell exposes the
decision in its JSON output (`providers.modelProvider`, `modelName`, `routeKind`,
`routeReason`, `cloudAttemptAllowed`).

## Local model planning route (v1.3)

`--planner local` (or `AETHER_PLANNER_PROVIDER=local`) selects `LocalModelPlanProvider`, which uses
the same bounded planning prompt/strict parser as the cloud adapter but calls only the loopback
transport through the local egress path. Missing/unavailable local model returns a typed provider
error; there is **no cloud fallback**. The supported profile is
[`qwen2.5:7b` (Apache-2.0)](evaluation/local-model-profile-qwen2.5-7b.md).

## Credential lifecycle (v1.3)

- Development default: `.env`/environment injection, loaded explicitly via `--env-file`; `.env` is
  git-ignored and never logged.
- Optional Windows Credential Manager source: `AETHER_CREDENTIAL_STORE=windows-credential-manager`.
  Store Generic credentials named `AetherWorkspace/<VARIABLE_NAME>` (for example
  `AetherWorkspace/OPENAI_API_KEY`) using your organisation's credential tooling or `cmdkey`.
- Rotation: replace the credential in the store and restart the shell; there is no secret caching
  outside the process. Diagnostics include variable names only, never values.
- Non-Windows hosts reject the Windows Credential Manager source with `PlatformNotSupportedException`;
  CI uses environment injection.

## Evaluation harness (AW-028)

`tools/Aether.ModelEval` runs the versioned synthetic gold corpus
(`docs/evaluation/command-corpus-v1.3.json`, 120 labelled items: 80 canonical-plan + 40
adversarial negatives) through one configured provider and records semantic plan accuracy,
denial accuracy, provider failures, repeated-trial latency percentiles, estimated tokens/cost and
a hardware fingerprint. It never records API keys or raw secrets; raw reports stay in the local
`.aether/evaluation/` directory. See [`tools/model-eval/README.md`](../tools/model-eval/README.md).
The deterministic CI baseline is documented in
[`results-2026-11-18-deterministic-baseline.md`](evaluation/results-2026-11-18-deterministic-baseline.md);
it is **not** a model-quality claim. TTFT is currently reported as unavailable (non-streaming
adapters) and is an explicit deviation, not a fabricated number.

First real smoke (2026-11-15): OpenAI `gpt-4o-mini` and Gemini `gemini-3.1-flash-lite`,
6/6 provider responses and 6/6 syntactically valid plan shapes each, avg latency ~1.3–1.4 s,
estimated total cost well below $0.01 for the run. Details:
[`docs/evaluation/results-2026-11-15.md`](evaluation/results-2026-11-15.md).

Model output is untrusted: the deterministic validator and capability authorizer remain the
only path to execution. The adversarial corpus command is never executed by the evaluation
harness.

## v1.3 evaluation status

The v1.0 gap assessment found the old evaluation was a six-command smoke. The v1.3 corpus/harness
expansion to ≥100 labelled commands with semantic/denial accuracy and repeated trials is tracked by
#88; do not treat the 2026-11-15 smoke as a quality or cost benchmark. Actual provider/local numbers
are published only from reproducible runs with a hardware/provider fingerprint.

## Known limits

- The smoke corpus is tiny; no quality ranking or statistical claim is made.
- Local model inference was not exercised in this environment (no local model installed);
  the optional profile is reported as unavailable rather than passed.
- Provider prices/model availability change; the Gemini 2.5 Flash-Lite model was closed to
  new users during implementation, so the next cheapest available tier was selected after a
  live availability check.
- `INTERNAL` data has no cloud path in the default policy; a future policy may allow an
  explicitly approved private deployment (requires a separate ADR).
