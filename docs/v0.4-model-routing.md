# v0.4 — provider configuration, model routing and evaluation

Status: v0.4 implementation baseline (2026-11-15). Synthetic data only; no production,
compliance or fixed-performance claims.

## Provider configuration

Configuration is resolved from environment variables or an explicitly loaded, git-ignored
`.env` file (`--env-file`, in-memory secret provider; the process environment is not
mutated; values are never logged). Defaults target the cheapest capable models; see
[`docs/evaluation/model-selection.md`](evaluation/model-selection.md).

| Variable | Purpose |
|---|---|
| `AETHER_MODEL_PROVIDER` | `openai` (default), `gemini`, `local` |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` | OpenAI-compatible chat-completions adapter |
| `GEMINI_API_KEY`, `GEMINI_BASE_URL`, `GEMINI_MODEL` | Native Gemini `generateContent` adapter (`x-goog-api-key`; default `gemini-3.1-flash-lite`) |
| `AETHER_LOCAL_MODEL_ENDPOINT`, `AETHER_LOCAL_MODEL` | Optional loopback local model (Ollama-compatible) |
| `AETHER_CLOUD_ENDPOINT`, `AETHER_CLOUD_API_KEY`, `AETHER_CLOUD_MODEL` | Generic OpenAI-compatible fallback adapter |

Unknown/incomplete configuration is reported by provider health (`providers` block of the
headless shell output) without any network I/O. A missing key fails closed.

## Model routing policy

`ModelRouter` makes the route explicit and testable per AI task:

| Data classification | Cloud attempt | Route |
|---|---|---|
| `PUBLIC` | Only when cloud is enabled **and** consent is recorded **and** provider is configured | cloud adapter (selected provider/model) |
| `INTERNAL` | Never by default | local model if configured, else deterministic local |
| `RESTRICTED` | Never | local model if configured, else deterministic local |
| `UNKNOWN` | Never (fail closed) | local model if configured, else deterministic local |

Cloud gating is additionally enforced by the single `EgressGateway` (policy + audit), so a
routing bug cannot bypass classification/consent enforcement. The headless shell exposes the
decision in its JSON output (`providers.modelProvider`, `modelName`, `routeKind`,
`routeReason`, `cloudAttemptAllowed`).

## Evaluation harness (AW-028)

`tools/Aether.ModelEval` runs the bounded synthetic command corpus
(`docs/evaluation/command-corpus.json`) through one configured provider and records:
provider/model, per-command latency, syntactically valid bounded plan shape, step count,
estimated tokens/cost and safe error codes. It never records API keys or raw secrets; raw
reports stay in the local `.aether/evaluation/` directory.

First real smoke (2026-11-15): OpenAI `gpt-4o-mini` and Gemini `gemini-3.1-flash-lite`,
6/6 provider responses and 6/6 syntactically valid plan shapes each, avg latency ~1.3–1.4 s,
estimated total cost well below $0.01 for the run. Details:
[`docs/evaluation/results-2026-11-15.md`](evaluation/results-2026-11-15.md).

Model output is untrusted: the deterministic validator and capability authorizer remain the
only path to execution. The adversarial corpus command is never executed by the evaluation
harness.

## Known limits

- The smoke corpus is tiny; no quality ranking or statistical claim is made.
- Local model inference was not exercised in this environment (no local model installed);
  the optional profile is reported as unavailable rather than passed.
- Provider prices/model availability change; the Gemini 2.5 Flash-Lite model was closed to
  new users during implementation, so the next cheapest available tier was selected after a
  live availability check.
- `INTERNAL` data has no cloud path in the default policy; a future policy may allow an
  explicitly approved private deployment (requires a separate ADR).
