# Model evaluation tools (v1.3)

## Corpus

`docs/evaluation/command-corpus-v1.3.json` is generated by
`tools/model-eval/generate-corpus-v1.3.py`. It contains **120 labelled synthetic commands**:
80 canonical reference-plan items and 40 adversarial/out-of-scope negatives. The canonical plan is
deliberately context-ref-agnostic (plan shape); context-ref choice is validated by the workflow
tests, not by the semantic corpus.

Re-generate deterministically:

```bash
python3 tools/model-eval/generate-corpus-v1.3.py
```

## Evaluation harness

`tools/Aether.ModelEval` supports `deterministic`, `local`, `openai` and `gemini` providers:

```bash
# deterministic harness/corpus baseline (CI-safe, no network)
dotnet run -c Release --project tools/Aether.ModelEval -- \
  --provider deterministic --corpus docs/evaluation/command-corpus-v1.3.json \
  --out .aether/evaluation/deterministic-baseline.json --trials 1

# real provider run (operator; .env is git-ignored)
dotnet run -c Release --project tools/Aether.ModelEval -- \
  --provider openai --env-file .env \
  --corpus docs/evaluation/command-corpus-v1.3.json \
  --out .aether/evaluation/openai-$(date +%Y%m%d).json --trials 2
```

Metrics: semantic plan accuracy, denial accuracy, provider failures, p50/p95/p99 latency,
character-based estimated tokens/cost (labelled **estimated**), hardware fingerprint. TTFT is
reported as **unavailable** for the current non-streaming adapters; no value is fabricated.

## Local model profile

The supported profile is `qwen2.5:7b` (Ollama, Apache-2.0, pinned layer digest) — see
[`docs/evaluation/local-model-profile-qwen2.5-7b.md`](../../docs/evaluation/local-model-profile-qwen2.5-7b.md).
Operator measurement:

```powershell
pwsh -File tools/model-eval/Measure-LocalModelProfile.ps1 -Model qwen2.5:7b -Trials 2
```

Attach the generated measurement JSON; do not claim latency/memory values outside that report.
